LOCKDOWN · FACILITATOR SHEET (4 LOCKS · 4 MINUTES)

BEFORE DOORS OPEN

  • Open the game URL once on every loaner phone while online (PWA caches for offline play).
  • Silent mode OFF, volume up to 80%, Auto-Lock disabled on all loaners.
  • One printed manual (A4, 5 pages, stapled) per station. Keep spare copies ready.
  • Booth QR code points directly to the deployed web app URL.

START A RUN

  1. Pick two players: Escapee holds the phone; Handler holds the manual.
  2. Escapee scans QR or opens loaner phone. On the main menu they pick theme or gentle mode if needed.
  3. Escapee taps ENTER THE HOUSE on the main menu. Timer begins immediately (4:00 on normal). THE MANUAL opens the digital manual; it has a MAIN MENU link back.
  4. Handler must never look at the phone. Sit face-to-face. No outside coaching.

20-SECOND BRIEFING SCRIPT

"You are locked inside a killer's house. You have four minutes to escape through four locked doors. One of you is the Escapee holding the phone; one is the Handler with the case file. You cannot look at each other's materials—talk fast, describe what you see, and give clear orders. Three strikes and he finds you. Sound up. Tap ENTER."

RESET BETWEEN PAIRS

  • End screen: tap PLAY AGAIN / TRY AGAIN for a fresh case code, or MAIN MENU to reset to the start. The MENU button in the HUD leaves a run in progress (asks first, clock held).
  • Swap roles if players wish. Hand the manual to the new Handler, page 1 on top.
  • Phone frozen or glitching? Hard refresh the browser; offline cache reloads in under 1 second.

STUCK PAIR COACHING (DO NOT GIVE ANSWERS)

  1. General: "Escapee: read the PLATE NAME." / "Handler: find that exact page."
  2. Tumbler: "Read pin colors and symbols left to right. Check the skull rule first."
  3. Glyphs: "Describe the four symbols cleanly. Do not invent names."
  4. Fuse Box: "Count the wires top to bottom. State which have warning tags."
  5. Execution Switch: "Escapee: read all six switch letters, left to right. Handler: find the switch with the case LETTER, then add SERIAL to the COLOR start number. Escapee: watch the number and flip as it appears."
  6. Still stuck after 45s on one lock: use staff answer key to give one subtle hint.

THEMES & GENTLE MODE

  • Themes: One-tap LIGHTS OUT / LIGHTS ON toggle on the main menu and HUD. Lights On is a dim, sickly yellow lit room. Toggling does not disturb the clock. URL: ?theme=light or ?theme=dark.
  • Gentle Mode: Checkbox on the main menu or URL ?gentle=1. Completely disables strobes, full-screen blackouts, and softens stingers for light-sensitive guests.

ANSWER KEY & DEBUGGING

  • Open /admin/ on a staff phone. Enter the 4-part case code from the Escapee's screen.
  • Direct URL: /admin/?case=K7-3-RED. Shows exact solutions for all 4 doors.
  • Test run with on-screen answers: /?case=K7-3-RED&debug (staff use only).

GUEST SAFETY & DISTRESS

  • The main menu displays prominent photosensitivity and jump scare warnings.
  • If a guest is scared or asks to stop: Stop immediately. Take the device, offer water, guide them out of the booth. Never pressure anyone to finish.
