LOCKDOWN · FACILITATOR SHEET

BEFORE DOORS OPEN

  • Open the game URL once on every loaner phone while online (it then works offline).
  • Silent mode OFF, volume up, Auto-Lock off on loaners. Visitors: ask them to do the same.
  • One printed manual (A4, 9 pages, stapled) per station. Spare copies in a folder.
  • QR code at the booth points at the game URL. Keep a printed copy of the URL too.

START A RUN

  1. Pick two players. Escapee holds the phone. Handler holds the manual.
  2. Escapee scans the QR, taps ENTER THE HOUSE. Warning screen: read it aloud if asked.
  3. Handler must not look at the phone. Sit face to face, phone toward the Escapee's chest.
  4. The clock starts at once. Do not coach during the run.

20-SECOND BRIEFING

"You are locked in a killer's house. One of you holds the phone: the Escapee. The other holds the manual: the Handler. You cannot see each other's screen, so talk fast and describe exactly. Three mistakes and he finds you. Silent mode off, volume up. Ready? Tap ENTER."

RESET BETWEEN PAIRS

  • End screen: tap PLAY AGAIN / TRY AGAIN. A new case code is generated.
  • Swap roles if they want. Hand the manual to the next Handler, page 1 on top.
  • Phone frozen or blank? Reload the page. It works offline once loaded.

STUCK PAIR (do not give answers)

  1. "Escapee: read me the plate name on the lock." / "Handler: find that page."
  2. "Read the four case code boxes again: letter, serial, last, color."
  3. "Describe the shapes, do not guess names."
  4. Still stuck after 45s on one lock: use the answer key, give one hint only, then step back.

ANSWER KEY

  • Open /admin/ on a staff phone. Type the case code shown on the screen. It lists every door's answer.
  • Or open /admin/?case=K7-3-RED. Do not show this page to visitors.
  • Game with a fixed case: /?case=K7-3-RED&debug (shows the answer on screen. Staff testing only).

SAFETY

  • Start screen warns about jump scares and flicker. Reduced effects checkbox removes flashing, motion and the big scare.
  • If anyone looks distressed: stop, let them leave. No pressure to finish.
  • Note for tuning: time each run, where they got stuck, what was unclear. Do not record people.
