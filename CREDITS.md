# Credits

## Thank you for playing

**LOCKDOWN · Blackthorn Manor** is a game by **D'SAITECH**.

| Area | Credit |
|---|---|
| Game design | D'SAITECH |
| Code (game, puzzle logic, validator, tests) | D'SAITECH |

| Booth materials (facilitator sheet, answer key, playtest plan) | D'SAITECH |

## Built with

- [Vite](https://vitejs.dev) for the build
- Vanilla JavaScript, CSS and the Web Audio API (no framework, no audio or image assets)
- [jsdom](https://github.com/jsdom/jsdom) for the smoke tests, [qrcode](https://github.com/soldair/node-qrcode) for the booth QR code

## Where the credit appears

- In the game: main menu, **Credits** screen, and the **ESCAPED** and **HE FOUND YOU** screens
- In the printed manual (`/manual/`, `docs/print/`): cover, running footer on every page, closing thank-you
- In `/facilitator/` and `/admin/`
- In `README.md` and everything under `docs/`
- In `package.json` (`author`) and the page metadata
